seconds each, maximum 48 seconds total. No seed 310 data enter the validation
mean. Both seeds use the same connectome; they vary stochastic input and odor
class assignment, not biological individuals. Four cases are not four independent
animals, and this small cohort provides no population significance claim.

interval, 150 Hz/50 ms activity proxy, recovery checks, weight floor, eta and

an effect-size failure does not cancel prospectively specified controls.

Report the unchanged per-case gate (S>=.15 and differences >=.10). The cohort

requires paired to exceed both controls in every case. This aggregation rule is
declared before results, not chosen afterwards. No retuning or additional cases.
